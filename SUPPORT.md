# Support

## Usage questions

For installation and library-use questions:

1. Review the [usage guide](docs/USAGE.md).
2. Search existing
   [discussions](https://github.com/ddtdanilo/Personal-Altium-Library/discussions)
   and issues.
3. Start a GitHub Discussion if the answer is not already available.

## Defects and component corrections

Use the repository's component issue form when a symbol or footprint appears
incorrect. Include the exact library entry, manufacturer part number, current
datasheet URL, observed behavior, and screenshots or measurements where useful.

Do not use public issues for sensitive security reports. Follow
[`SECURITY.md`](SECURITY.md) instead.

Support is provided by maintainers and community contributors on a best-effort
basis. No response-time guarantee is offered.
